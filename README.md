    # 奶茶门店订单管理系统
    > FastAPI + SQLAlchemy 2.0 练手项目，课程作业Demo
    
    ## 技术栈
    - FastAPI
    - SQLAlchemy 2.0 ORM
    - MySQL
    
    ## 业务功能
    1. 饮品管理：新增饮品、查询单个饮品、查询全部饮品
    2. 订单管理：创建订单（下单自动扣库存，事务保证数据一致性）、查询单条订单、查询全部订单
    3. 业务约束：库存不足禁止下单；外键关联订单-饮品；参数校验
    
    ## 运行说明
    1. 创建MySQL数据库 `milk_tea_db`
    2. 修改代码中数据库连接为自己本地账号密码
    3. 运行程序，访问接口文档： http://127.0.0.1:8000/docs
